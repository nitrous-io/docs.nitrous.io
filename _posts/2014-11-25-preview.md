# Previewing Your Application

*Each container is provided with a HOSTNAME which can be used to preview your app within the web browser. If the app is
running on a specific port, append this to the end of the hostname URL for previewing.*

## Locating Your Preview URL

To view your preview URL, open your [Nitrous Dashboard](https://pro.nitrous.io/app/#/) and locate the **HOSTNAME** field
within your application configuration.

![Hostname]({{site.baseurl}}/images/articles/preview/hostname.png)

In the example above, the hostname is `rails-1337.nitrouspro.com`. Paste this URL into your address bar along with a port number to view your app once running.

## Previewing Your App

Before previewing your app you will need to ensure the app is running. Within the app terminal, cd into the project
directory and run the command needed to run the app. You will want to ensure your app's host is configured for
0.0.0.0.

In this example we will run a Rails app:

    action@rails-3675:~/workspace/app$ rails server
    => Booting WEBrick
    => Rails 4.1.7 application starting in development on http://0.0.0.0:3000

Once the app is running there are 2 ways to preview the app.

1. Within the container settings, navigate to the container settings and click **Preview**. This option is only
   available if your container has a preview port configured.

![Preview]({{site.baseurl}}/images/articles/preview/preview.png)

2. Past your preview URL along with your port into your web browser to view the app. Following the example above, the URL will be `http://rails-1337.nitrouspro.com:3000`.

## Configuring Your Preview Port

In order to utilize the **Preview** links you will need to utilize a Starter Template or configure your
container manually. To configure a container's preview port, navigate in the menu to **Account > Account Settings** and enable **Show Advanced Options**.

Navigate to your container settings and click the **Configuration** tab. In order to configure your app to run on port 80, add a new port binding with the host port of 80, and set the
container port to the port it initially runs on.

>Note: If there was a port binding previously set for the same port your app
runs on then you will need to remove it.

Once the port binding is set to 80, add a environment variable with the value
`NITROUS_PREVIEW_PORT:80` to allow the preview button to open the app.

![Preview Port]({{site.baseurl}}/images/articles/preview/preview-port.png)
