# Previewing Your Application

<p class="intro">Nitrous offers the ability to preview your app on a publicly availble URL which you can share with anyone.</p>

## From the Web IDE

To preview your app, navigate to **Preview > Port 3000** within the menu bar.

![Preview Port 3000]({{site.baseurl}}/images/articles/preview/preview-port-3000.png)

>If your app isn't configured to run automatically then you will need to run the app within the console before previewing. Cd into the project directory and run your app on 0.0.0.0:3000 (or another port of your choice) in order to preview.

## From the Dashboard

You can quickly preview your app by opening the [Nitrous Dashboard](https://pro.nitrous.io/app/#/) and from there clicking the **Preview** link.

![Preview]({{site.baseurl}}/images/articles/preview/preview.png)

## Configuring Your Preview Port

In order to utilize the **Preview** links you will need to utilize a Starter Template or configure your
container manually. To configure a container's preview port, navigate in the menu to **Account > Account Settings** and enable **Show Advanced Options**.

Navigate to your container settings and click the **Configuration** tab. Here you will be able to configure your app to run on any port, which in this example we will configure it for port 80.

Add a new port binding with the host port of 80, and set the container port to the port which the app is configured to utilize.

>Note: If there was a port binding previously set for the same port your app
runs on then you will need to remove it.

Once the port binding is set to 80, add a environment variable with the value
`NITROUS_PREVIEW_PORT:80` to allow the preview button to open the app.

![Preview Port]({{site.baseurl}}/images/articles/preview/preview-port.png)

## Previewing a Static HTML Page

*In situations where you just need to preview a static file without running a web server, try this out.*

Using Python you can run a small HTTP server in the project directory or your choice, allowing you to quickly preview any
HTML file needed.

To get started, navigate to your project folder within the terminal and run `python -m SimpleHTTPServer 3000`.

    $ cd ~/workspace/tutorial
    $ python -m SimpleHTTPServer 3000
    Serving HTTP on 0.0.0.0 port 3000 ...

If everything runs smoothly then you will see the output "Serving HTTP on 0.0.0.0 port 3000 ...".

Navigate to **Preview > Port 3000** within the menu bar to view the static content. Click the file within the directory listing which you wish to view. Any referenced CSS/JavaScript will be loaded.

![Preview Static Page]({{site.baseurl}}/images/articles/preview/preview-static-page.png)
