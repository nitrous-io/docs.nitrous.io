## Installing the Nitrous.IO Toolbelt

Straightforward installation tools for each operating system



### Mac OS X

Step 1: Download and run the [Nitrous.IO Command Line Interface (CLI) Installer Package](https://osx.nitrous.io/nitro-latest-darwin_amd64.pkg) for OS X.

Step 2: In Terminal, authenticate with your Nitrous.IO credentials.

{% highlight bash %}
nitro login
{% endhighlight %}

And you’re set! Continue with the [User Guide] to start using the Nitro CLI to create Hosts, Images and Containers. 



### Debian/Ubuntu

Step 1a: Add the Nitrous.IO repository key to your local keychain.

{% highlight bash %}
sudo apt-key adv --recv-keys --keyserver keyserver.ubuntu.com 6B19EAE0
{% endhighlight %}

Step 1b: Then, add the Nitrous.IO repository to your apt-sources list.

{% highlight bash %}
echo "deb https://get.nitrous.io nitrous main" | sudo tee /etc/apt/sources.list.d/nitrous.list
{% endhighlight %}

Step 2: Update and install the Nitrous.IO Command Line Interface (CLI).

{% highlight bash %}
sudo apt-get update
sudo apt-get install nitro
{% endhighlight %}

Step 3: Authenticate with your Nitrous.IO credentials.

{% highlight bash %}
nitro login
{% endhighlight %}


And you’re set! Continue with the [Getting Started Tutorial]({{site.url}}docs/getting-started/) to start using the Nitro CLI to create Hosts, Images and Containers.
