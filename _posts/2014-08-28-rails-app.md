# Setting up a new Rails Application with Postgres

## Overview

This will quickly walk you through setting up a new Rails Application and pushing it to Docker Hub for sharing purposes with co-developers.

This guide assumes that you have the [Nitro CLI installed]({{site.baseurl}}/download/) and a [Host created on Nitrous.IO]({{site.baseurl}}/getting-started/).

## Step 1: Create a Container using the [Ruby image](https://registry.hub.docker.com/u/nitrousio/ruby/) from Docker Hub

Let's start with creating a container, utilizing a pre-built Ruby image we have ready for you, and specify a host which you have already created.

{% highlight bash %}
$ nitro create HOST_NAME -s rails-app -i nitrousio/ruby -p public:3000:3000
Creating container on 'HOST_NAME'. Please wait...
Created new container: 'rails-app'
Slug         Image             State
rails-app    nitrousio/ruby    running
{% endhighlight %}

Using this command, a new container named 'rails-app' would be created with Ports forwarded 3000:3000 using the Image 'nitrousio/ruby'.

## Step 2: Prepare a Postgres Database

To connect your Rails app to a Postgres database, we will need to make a separate container for it. Start by creating a volume. This is where the actual data will be stored.

{% highlight bash %}
$ nitro volumes:create HOST_NAME postgres
Creating volume on 'HOST_NAME'. Please wait...
Created new volume: 'postgres'
{% endhighlight %}

Next, create the Postgres container which will run the database service. Create a private container, and forward port 5432 so the database can be accessed.

{% highlight bash %}
$ nitro create HOST_NAME -i postgres -s postgres -p private:5432:5432 -v postgres:/var/lib/postgresql/data
Creating container on 'HOST_NAME'. Please wait...
  Created new container: 'postgres'
  Slug        Image       State
  postgres    postgres    running
{% endhighlight %}

>Notice that when specifying the port we appended `private:` before it. You can specify if you want the container to be `private` or `public` to outside connections by specifying this option.

## Step 3: Connect to the Rails Container and Prepare Your Rails Environment

Shell into the rails-app container with the user 'action'.

{% highlight bash %}
$ nitro shell rails-app -u action
{% endhighlight %}

Install the following libraries and tools with apt-get:

{% highlight bash %}
$ sudo apt-get install libpq-dev postgresql-client
{% endhighlight %}

Now that libpq-dev is installed, you can install the pg gem:

{% highlight bash %}
$ gem install pg
{% endhighlight %}

## Step 4: Create and Configure Your Rails App

Now it's time to create the rails app.

{% highlight bash %}
rails new myapp --database=postgresql
{% endhighlight %}

Add the pg gem to your `Gemfile`:

{% highlight bash %}
gem 'pg'
{% endhighlight %}

Once the Rails project is created, edit `myapp/config/database.yml` to utilize the following settings:

{% highlight ruby %}
default: &default
  adapter: postgresql
  encoding: unicode
  pool: 5
  host: <%= ENV['__HOST'] %>
  port: 5432
  username: postgres
  password:

development:
  <<: *default
  database: myapp_development

test:
  <<: *default
  database: myapp_test

production:
  <<: *default
  database: myapp_prod
{% endhighlight %}

>Each Nitrous container is assigned a private IP which you can access with the environment variable `$__HOST`. Notice how this is used in `database.yml` under the host configuration.

## Step 5: Run the App

Before running the app you will need to create and migrate the database.

{% highlight bash %}
$ rake db:create
$ rake db:migrate
{% endhighlight %}

Now you can run the Rails server.

{% highlight bash %}
$ rails server
{% endhighlight %}

Now we can access the Rails application locally within the container.

{% highlight bash %}
$ curl localhost:3000
{% endhighlight %}

## Step 6: Access the Service on Web

Find the URL to your host and point your browser to your new Rails application.

{% highlight bash %}
$ nitro hosts:inspect HOST_NAME
{% endhighlight %}

You have now successfully set up a new Rails application with Postgres.
