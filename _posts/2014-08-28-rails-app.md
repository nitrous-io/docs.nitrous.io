# Setting up a new Rails Application with PostgreSQL & Redis


## Overview

This will quickly walk you through setting up a new Rails Application and pushing it to Docker Hub for sharing purposes with co-developers. 

This guide assumes that you have the [Nitro CLI installed](/docs/toolbelt/) and a [Host created on Nitrous.IO](/docs/getting-started/).


## Step 1: Pull a [ruby Image](https://registry.hub.docker.com/u/nitrousio/ruby/) from Docker Hub

The Image you are pulling is a pre-built ruby Image we have ready for you. 

{% highlight bash %}
$ nitro images:pull HOST_NAME nitrousio/ruby

Pulling image 'nitrousio/ruby' to 'HOST_NAME'...
Slug              Tag       ID                                                                  Name   Created                                 Size         Virtual Size
nitrousio/ruby    latest    ba0d4fa7b29e84d2383ed4e2a31ef230dd9dde50ecb6344933c97690f5a8e53c           2014-09-04 21:30:55.404943 +0000 UTC    146960089    864532641

{% endhighlight %}


## Step 2: Create a Container using the Ruby Image

{% highlight bash %}
$ nitro create HOST_NAME -s railsapp -i nitrousio/ruby -p 3000:3000

Creating container on 'HOST_NAME'. Please wait...
Created new container: 'railsapp'
Slug         Image             State
railsapp    nitrousio/ruby    running
{% endhighlight %}

Using this command, a new Container named 'railsapp' would be created with Ports forwarded 3000:3000 using the Image 'nitrousio/ruby'.


## Step 3: Connect to the Container via shell

We can ensure that the Container came up properly by accessing it.

{% highlight bash %}
$ nitro shell railsapp
{% endhighlight %}

Now we can access the Rails application locally within the Container.

{% highlight bash %}
$ curl localhost:3000
{% endhighlight %}


## Step 4: Access the Service on Web

Find the URL to your host and point your browser to your new Rails application.

{% highlight bash %}
$ nitro hosts:inspect HOST_NAME
{% endhighlight %}

## Step 8: Share your application with co-developers 

Simply push your Image to a Docker Hub registry.
If you would like to push it to a Private Registry, please perform Step 1 of the [Private Registry Tutorial](/docs/private-registry/) before continuing with this command. 

{% highlight bash %}
$ nitro images:push HOST_NAME nitrousio/ruby USERNAME/REPO_NAME

Pushing image 'nitrousio/ruby' on 'HOST_NAME' to 'USERNAME/REPO_NAME'...
Pushed image
{% endhighlight %}

You have now successfully set up a new Rails application with PostgreSQL & Redis.
