### Setting up a new Rails Application with PostgreSQL & Redis


#### Overview

This will quickly walk you through setting up a new Rails Application and pushing it to Docker Hub for sharing purposes with co-developers. 

This guide assumes that you have the [Nitro CLI installed]({{site.url}}docs/toolbelt/) and a [Host created on Nitrous.IO](({{site.url}}docs/getting-started/).


#### Step 1: Pull a pre-built [ruby Image](https://registry.hub.docker.com/u/nitrousio/ruby/) we have ready for you.

{% highlight bash %}
nitro images:pull HOST_NAME nitrousio/ruby
{% endhighlight %}


#### Step 2: Create a Container using the Ruby Image.

{% highlight bash %}
nitro create HOST_NAME -s railsapp -i nitrousio/ruby -p 3000:3000
{% endhighlight %}

Using this command, a new Container named 'railsapp' would be created with Ports forwarded 3000:3000 using the Image 'nitrousio/ruby'.


#### Step 3: Connect to the Container via shell.

We can ensure that the Container came up properly by accessing it.

{% highlight bash %}
nitro shell railsapp
{% endhighlight %}

Now we can access the Rails application locally within the Container.

{% highlight bash %}
curl localhost:3000
{% endhighlight %}


#### Step 4: Access the Service on Web.

Find the URL to your host and point your browser to your new Rails application.

{% highlight bash %}
    nitro hosts:inspect HOST_NAME
{% endhighlight %}

You have now successfully set up a new Rails application. 

#### Step 5: Pull a PostgreSQL Image from DockerHub and create a Container using this Image.

#### Step 6: Pull a Redis Image from DockerHub and create a Container using this Image.

#### Step 7: Link the Database containers with your new Rails application Container.


#### Step 8: Share your application with co-developers by simply pushing it onto Docker Hub.

{% highlight bash %}
    nitro images:push HOST_NAME nitrousio/ruby USERNAME/REPO_NAME
{% endhighlight %}

Check out the [Private Registry Tutorial]({{site.url}}docs/private-registry/) to push your application onto a Private Registry.
