### Setting up a new Rails Application with PostgreSQL & Redis


#### Overview

This will quickly walk you through setting up a new Rails Application from scratch using a Dockerfile. This guide assumes that you have the Nitro CLI installed and a Host created. If you haven't, please check out the Getting Started guide. 


#### Step 1: Create a new Rails application. (pre-install gem dependencies for Rails before proceeding with this step)

{% highlight bash %}
rails new app 
cd app
rails server 
{% endhighlight %}

You can preview your application on your local machine at localhost:3000.

Step 1b: Alternately, you can also clone an existing Rails application from a GitHub Repository. 

{% highlight bash %}
git clone https://github.com/erichuang91/rails.git
{% endhighlight %}


#### Step 2: Create a Dockerfile using your local editor. 

A Dockerfile is a text file that specifies instructions to automatically build a Docker Image.

{% highlight bash %}
FROM ddollar/rails:2.1.2
ADD . /app
{% endhighlight %}

Save the file as 'Dockerfile' in your Rails application folder that you've just created.


#### Step 3: Compress the Rails application folder into a .tar file. Ensure that you're within the Rails application folder directory before proceeding. 

{% highlight bash %}
tar -cvf railsapp.tar .
{% endhighlight %}


#### Step 4: Build the Docker Image using the .tar file.

{% highlight bash %}
nitro images:build HOST_NAME ./railsapp.tar
{% endhighlight %}


#### Step 5: Create a Docker Container using the new Image.

{% highlight bash %}
nitro create HOST_NAME -i IMAGE_NAME -s railsapp -p 3000:3000
{% endhighlight %}

Using this command, a new Container named 'railsapp' would be created with Ports forwarded 3000:3000.


#### Step 6: Connect to the Container via shell.

We can ensure that the Container came up properly by accessing it.

{% highlight bash %}
nitro shell railsapp
{% endhighlight %}

Now we can access the Rails application locally within the Container.

{% highlight bash %}
curl localhost:3000
{% endhighlight %}


#### Step 7: Access the Service on Web.

Find the URL to your host and point your browser to your new Rails application.

{% highlight bash %}
    nitro hosts:inspect HOST_NAME
{% endhighlight %}

You have now successfully set up a new Rails application.
