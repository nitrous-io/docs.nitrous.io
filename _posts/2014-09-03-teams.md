# Teams and Sharing Overview

## Overview

*In this tutorial you will learn how to create a container, modify and
commit any changes, and create additional images from the original.*

## Step 1: Pull an Existing Image into Your Host

Assuming you have already created a host and logged into the Docker Hub
registry, pull the Ubuntu image from the Nitrous Docker Hub repository.

{% highlight bash %}
nitro images:pull HOST_NAME nitrousio/ubuntu
{% endhighlight %}

## Step 2: Setup a Data Volume

To store your data in the container you are about to create you will
first need to create a volume.

{% highlight bash %}
$ nitro volumes:create HOST_NAME IMAGE_NAME
{% endhighlight %}

## Step 3: Create a Container with the Ubuntu Image

Next, create a container utilizing the Ubuntu image and the data volume
you just prepared. This will build your dev environment in which you can work within.

{% highlight bash %}
$ nitro create HOST_NAME -s CONTAINER_NAME -i IMAGE_NAME -v VOLUME_NAME:/data
{% endhighlight %}

## Step 2: Log into your Container and Customize it

Now that you have Ubuntu built on a container, check to see if it is
running. If it is not then now is the time to start it up.

{% highlight bash %}
$ nitro list
Listing all containers...
Name              Image            State
CONTAINER_NAME    ubuntu           stopped

$ nitro start CONTAINER_NAME
Starting container...
Slug              Image            State
CONTAINER_NAME    ubuntu           running
{% endhighlight %}

Attach to your container at this time.

{% highlight bash %}
$ nitro attach CONTAINER_NAME
{% endhighlight %}

Now you are running within the ubuntu container. Let's customize this container with some new dotfiles.

Run the following command to install [YADR](https://github.com/skwp/dotfiles/):

{% highlight bash %}
$ sh -c "`curl -fsSL https://raw.github.com/skwp/dotfiles/master/install.sh`"
{% endhighlight %}

Make any other customization to the container that you want for your initial dev environment setup and then exit out of the container by running `exit` in the prompt.

## Step 3: Commit Your Customizations Within the Container

After making the customizations to your container, commit the changes so that you can share or restore this image later.

{% highlight bash %}
$ nitro commit CONTAINER_NAME
{% endhighlight %}

This will commit your container to a new image.

## Step 4: Push to Your Registry

Now that you have a customized image, push it to the Docker Hub repo:

{% highlight bash %}
$ nitro images:push IMAGE_NAME
{% endhighlight %}

## Step 5: Reuse

You can reuse the image you created anywhere that Docker is supported. Let's create a new container using your new image.

{% highlight bash %}
$ nitro images:pull HOST_NAME DOCKER_NAME/IMAGE_NAME
{% endhighlight %}
