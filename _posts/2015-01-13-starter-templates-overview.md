# Starter Templates Overview

<p class="intro">Starter templates include a sample app with a database already configured, allowing you to start coding immediately.</p>

## Creating a New Application

When creating a new [Workspace](https://pro.nitrous.io/app/#/workspaces/new) you will have the option to select from a variety of starter templates.

![Starter Templates]({{site.baseurl}}/images/articles/templates/starter-templates.png)

Select the template you wish to use and select **Create**.
