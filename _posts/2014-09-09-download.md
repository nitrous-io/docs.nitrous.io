# Installing the Nitrous.IO Toolbelt

*Straightforward installation tools for each operating system*

## Mac OS X

### Step 1: Install the Nitrous.IO Command Line Interface (CLI) for Mac OS X

Download and Install the Nitrous.IO CLI for [Mac - OS X](https://osx.nitrous.io/nitro-latest-darwin_amd64.pkg)

### Step 2: In Terminal, authenticate with your Nitrous.IO credentials

Set up your [Nitrous.IO account](https://www.nitrous.io) before performing this step.

{% highlight bash %}
$ nitro login
{% endhighlight %}

## Debian/Ubuntu

### Step 1: Add the Nitrous.IO repository key to your local keychain

Then, add the Nitrous.IO repository to your apt-sources list.

{% highlight bash %}
$ sudo apt-key adv --recv-keys --keyserver keyserver.ubuntu.com 6B19EAE0
$ echo "deb https://get.nitrous.io nitrous main" | sudo tee /etc/apt/sources.list.d/nitrous.list
{% endhighlight %}

### Step 2: Update and install the Nitrous.IO Command Line Interface (CLI)

{% highlight bash %}
$ sudo apt-get update
$ sudo apt-get install nitro
{% endhighlight %}

### Step 3: Authenticate with your Nitrous.IO credentials

First, create a [Nitrous.IO account](https://www.nitrous.io) to setup your login credentials. From there you can login with the Nitrous Toolkit:

{% highlight bash %}
$ nitro login
{% endhighlight %}
