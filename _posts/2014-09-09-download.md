# Installing the Nitrous.IO Toolbelt

*Straightforward installation tools for each operating system*

## Mac OS X

### Step 1: Install the CLI via the Terminal

**Note: By installing the Nitrous.IO CLI you agree to the terms of [Beta Agreement](http://nitrous-io.github.io/docs.nitrous.io/beta-agreement/)** 

Open a terminal window and type: 

{% highlight bash %}
curl -s https://osx.nitrous.io/install.sh | sh
{% endhighlight %}

### Step 2: Authenticate with your Nitrous.IO credentials

Use your Nitrous.IO account credentials to login or create a [Nitrous.IO account](https://www.nitrous.io) if you don't have one.

{% highlight bash %}
$ nitro login
{% endhighlight %}

## Debian/Ubuntu

**Note: By installing the Nitrous.IO CLI you agree to the terms of [Beta Agreement](http://nitrous-io.github.io/docs.nitrous.io/beta-agreement/)** 

### Step 1: Add the Nitrous.IO repository key to your local keychain

Then, add the Nitrous.IO repository to your apt-sources list.

{% highlight bash %}
$ sudo apt-key adv --recv-keys --keyserver keyserver.ubuntu.com 6B19EAE0
$ echo "deb https://get.nitrous.io nitrous main" | sudo tee /etc/apt/sources.list.d/nitrous.list
{% endhighlight %}

### Step 2: Update and install the Nitrous.IO Command Line Interface (CLI)

{% highlight bash %}
$ sudo apt-get update
$ sudo apt-get install nitro
{% endhighlight %}

### Step 3: Authenticate with your Nitrous.IO credentials

Use your Nitrous.IO account credentials to login or create a [Nitrous.IO account](https://www.nitrous.io) if you don't have one.

{% highlight bash %}
$ nitro login
{% endhighlight %}
