# Customizing and Sharing Images

## Overview

*In this tutorial you will learn how to create a container, modify and
commit any changes, and create additional images from the original.*

## Step 1: Pull an Existing Image into Your Host

Assuming you have already created a host and logged into the Docker Hub
registry, pull the Ubuntu image from the Nitrous Docker Hub repository.

{% highlight bash %}
nitro images:pull HOST_NAME nitrousio/ruby
{% endhighlight %}

## Step 2: Setup a Data Volume

To store your data in the container you are about to create you will
first need to create a volume.

{% highlight bash %}
$ nitro volumes:create HOST_NAME VOLUME_NAME
{% endhighlight %}

## Step 3: Create a Container with the Ubuntu Image

Next, create a container utilizing the Ubuntu image and the data volume
you just prepared. This will build your dev environment in which you can work within.

{% highlight bash %}
$ nitro create HOST_NAME -s CONTAINER_NAME -i IMAGE_NAME -v VOLUME_NAME:/data
Creating container on 'HOST_NAME'. Please wait...
Created new container: 'CONTAINER_NAME'
Slug              Image             State
CONTAINER_NAME    nitrousio/ruby    running
{% endhighlight %}

## Step 2: Log into your Container and Customize it


{% highlight bash %}
$ nitro shell CONTAINER_NAME -u action
{% endhighlight %}

Now you are running within the ubuntu container. Let's customize this container with some new dotfiles. If you don't have any dotfiles of your own, aake a look at [dotfiles.github.io](https://dotfiles.github.io/) for a guide and examples.

Make any other customization to the container that you want for your initial dev environment setup and then exit out of the container by running `exit` in the prompt.

## Step 3: Commit Your Customizations Within the Container

After making the customizations to your container, commit the changes so that you can share or restore this image later.

{% highlight bash %}
$ nitro commit CONTAINER_NAME -t IMAGE_NAME
{% endhighlight %}

This will commit your container to a new image.

## Step 4: Push to Your Registry

Now that you have a customized image, push it to the Docker Hub repo.
You will need to [add a new repository](https://registry.hub.docker.com/account/repositories/add/)
to your account before running the next command.

{% highlight bash %}
$ nitro images:push HOST_NAME IMAGE_NAME REGISTRY_USERNAME/REPO_NAME
{% endhighlight %}

## Step 5: Reuse

You can reuse the image you created anywhere that Docker is supported. Let's create a new container using the image you just created.

If you or a colleague are working with a new host then you will need to pull the image from your Docker Hub repo:

{% highlight bash %}
$ nitro images:pull HOST_NAME DOCKER_NAME/IMAGE_NAME
{% endhighlight %}

Check to ensure the image can be found on your host by running `$ nitro images HOST_NAME`. Create a new volume and container with your image.

{% highlight bash %}
$ nitro volumes:create HOST_NAME VOLUME_NAME
$ nitro create HOST_NAME -s CONTAINER_NAME -i IMAGE_NAME -v VOLUME_NAME:/data
{% endhighlight %}

Shell into your new container to see the cloned environment:

{% highlight bash %}
$ nitro shell CONTAINER_NAME -u action
{% endhighlight %}
