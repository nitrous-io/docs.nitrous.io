## Nitrous.IO Toolbelt

straightforward installation tools for each operating system



### Mac OS X

Step 1: Download and run the [Nitrous.IO Command Line Interface (CLI) Installer Package] for OS X.
	
Step 2: In Terminal, authenticate with your Nitrous.IO credentials. 

    nitro login

And you’re set!. Continue with the [User Guide] to start using the Nitro CLI to create Hosts, Containers and Images.



### Debian/Ubuntu

Step 1a: Add the ______ repository key to your local keychain.
```
sudo apt-key adv --recv-keys --keyserver keyserver.ubuntu.com 6B19EAE0
```
Step 1b: Then, add the ______ repository to your apt-sources list.
```
echo "deb https://get.nitrous.io nitrous main" | sudo tee /etc/apt/sources.list.d/nitrous.list
```

Step 2: Update and install the Nitrous.IO Command Line Interface (CLI)
```
sudo apt-get update
sudo apt-get install -yq nitro
```

Step 3: Authenticate with your Nitrous.IO credentials.
```
nitro login
```

    
And you’re set!. Continue with the [User Guide] to start using the Nitro CLI to create Hosts, Containers and Images.
